# Supply Chain & Logistics Performance Analytics

An interactive Power BI dashboard analyzing 180K+ supply chain transactions to monitor sales, profit, delivery performance, shipping efficiency, and regional KPIs.

## Tools Used
- Power BI
- Power Query (data cleaning and transformation)
- DAX (KPI development, time-based analysis, operational metrics)

## Dashboard Features
- 5-page interactive dashboard
- Drill-through and slicers
- Delivery performance analysis
- Product profitability
- Regional performance
- Delivery-delay root-cause analysis
